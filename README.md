# GT-Tool
简单的GTA5数据备份小工具  
支持导入导出存档,自电台音乐 键位以及画面设置  
附带一些其他功能 适配传承版+增强版  
特色:  
双版本选择,可识别多存档ID单独或全部导入导出,同时关联对应子项,未勾选内容不会进行操作  
导出导入均兼容ZIP或文件夹,自动识别备份纯音乐目录或者纯存档文件导入  
自电台音乐批量导入自动提醒不兼容格式  
执行关键操作检测游戏是否运行防止错误操作  
完全干净离线不含任何外挂程序
